# 函数拟合器

一个基于浏览器的交互式神经网络函数拟合可视化工具。你可以自由选择目标函数、调整函数参数与网络结构，实时观察小型多层感知机（MLP）如何学习拟合曲线。

## 功能特性

- **多种目标函数**：多项式、正弦波、双曲正切、绝对值、三次函数、高斯、混合波。
- **自由调整函数参数**：振幅、频率、相位、偏移、系数等，实时改变目标曲线。
- **可定制神经网络**：
  - 隐藏层大小：8–128
  - 隐藏层数量：1–3
  - 激活函数：Tanh / ReLU / Leaky ReLU / Sigmoid
  - 学习率：0.001–0.2
  - 训练轮数：100–3000
- **实时可视化**：
  - 蓝色曲线：目标函数
  - 橙色曲线：网络预测
  - 灰色点：训练样本
  - 粉色曲线：损失下降过程
- **日间/夜间模式**：右下角圆形按钮切换，偏好自动保存。
- **训练中可重置**：随时中断当前训练并重新开始。

## 运行方式

无需构建工具，只需要一个静态 HTTP 服务器。

```bash
cd function-fitter
python3 -m http.server 8000
```

然后在浏览器打开：

```text
http://localhost:8000
```

> 注意：由于使用了 ES Module 和 `localStorage`，建议通过 HTTP 服务器访问，而不是直接双击打开 HTML 文件。

## 浏览器要求

- 支持 ES Module 的现代浏览器（Chrome、Firefox、Edge、Safari 等）。
- 启用 JavaScript。

## 训练说明

- 目标函数输出会自动归一化到零均值、单位方差，便于网络稳定学习。
- 损失图显示的是原始尺度的均方误差（MSE）。
- 训练过程中预测曲线以较低分辨率渲染以保证流畅度，训练结束时会自动细化。

## 快捷键

- 右下角圆形按钮：切换日间/夜间主题。
- 「开始训练」/「重置」：控制训练流程。
